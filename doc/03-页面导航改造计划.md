# 页面导航改造计划

## 目标

稳定 Element Wiki 的页面导航主链路，确保文档切换、OIDC 登录回跳、权限控制、浏览器历史和深链接刷新行为一致。

认证模型保持不变：项目只使用配置中的单一 OIDC Provider，不增加本地密码登录或多 Provider 选择。

## 实施顺序

### 阶段一：主链路稳定

1. 修复 `/docs/A` 切换到 `/docs/B` 时组件复用导致的旧内容问题。
2. 修复 `/docs/A/edit` 切换到 `/docs/B/edit` 时编辑器、草稿和自动保存目标错配问题。
3. 登录前记录当前路径，OIDC 登录成功后返回原始页面。
4. 保持登录回跳使用已校验的站内路径，并继续由后端阻止开放重定向。

验收标准：

- 文档查看页从 A 切换到 B 后，标题、正文、目录和权限状态均属于 B。
- 编辑页从 A 切换到 B 后，编辑器内容、草稿和提交目标均属于 B。
- 访问受保护页面后完成 OIDC 登录，能够返回原始页面。

### 阶段二：认证与权限导航

1. 为路由增加认证和权限元数据。
2. 未登录访问受保护页面时跳转 `/login`，并保留原始目标。
3. 无权限访问页面时显示明确的无权限状态，而不是空白或只显示 API 错误。
4. 统一处理 401、403、404 和网络错误。

重点页面：

```text
/admin
/settings/tokens
/trash
/docs/:id/edit
```

验收标准：

- 未登录用户不能进入受保护页面内容。
- viewer、editor、admin 的页面入口和直接 URL 访问结果符合权限码。
- 401、403 和资源不存在时都有明确用户反馈。

### 阶段三：导航状态一致性

1. 根据当前路由参数高亮侧栏文档。
2. 增加未知路由 Not Found 页面。
3. 使用 URL query 保存管理后台 Tab：

```text
/admin?tab=settings
/admin?tab=users
/admin?tab=backups
```

4. 验证浏览器前进、后退和刷新后状态能够恢复。
5. 统一 `router.push`、`router.replace` 和整页跳转的使用规则。

验收标准：

- 当前文档在侧栏始终有明确高亮。
- 未知 URL 显示 Not Found 页面。
- 管理 Tab 刷新、前进和后退后保持一致。
- 页面内导航不会产生无意义的重复历史记录。

### 阶段四：部署与深链接

1. 明确前端静态资源的生产提供方式。
2. 为 `/docs/*`、`/search`、`/admin` 等路径配置 SPA fallback。
3. 验证直接打开和刷新深链接不会返回 404。
4. 保持 OIDC 回调地址、前端地址和 Cookie 主机名一致。

验收标准：

- 直接刷新文档、搜索和管理页面能够正常加载。
- 本地开发统一使用 `localhost` 或统一使用 `127.0.0.1`，不混用。
- 生产环境使用 HTTPS、`secure_cookies: true` 和匹配的前端公共地址。

### 阶段五：测试补齐

增加以下测试：

1. 查看页 A 到 B 的组件复用测试。
2. 编辑页 A 到 B 的编辑器和草稿切换测试。
3. 未登录访问受保护路由测试。
4. viewer、editor、admin 权限导航矩阵测试。
5. OIDC 登录后恢复原始目标测试。
6. 侧栏高亮测试。
7. Not Found 测试。
8. 401、403、404 和网络错误页面测试。
9. 管理 Tab query、刷新、前进后退测试。
10. 真实浏览器深链接刷新测试。

### 阶段六：收尾验证

1. 运行前端测试和构建。
2. 运行 `go test ./...` 和 `go vet ./...`。
3. 手动验证 OIDC 登录、登出、原页面回跳和 Cookie。
4. 更新 README 中的导航和部署说明。
5. 按 `doc/ROADMAP.md` 的实际任务状态更新进度。

## 当前已知问题

- `DocView.vue` 和 `EditView.vue` 只在 `onMounted` 中加载数据，同一路由记录切换文档时可能复用旧组件状态。
- 路由守卫当前只刷新权限，不阻止未认证或无权限页面访问。
- 登录入口和登录成功处理存在固定回首页的路径，尚未完整恢复登录前目标。
- 前端使用 `createWebHistory()`，生产静态资源服务需要配置 SPA fallback。
- 未定义 Not Found 路由。
- 侧栏 `activeId` 尚未与当前路由参数接通。
- 管理后台 Tab 尚未写入 URL。
- 部分页面的 API 错误状态处理不完整。

## 完成定义

本计划完成需要同时满足：

- 上述主链路和权限验收标准全部通过。
- 新增关键导航测试全部通过。
- 前端测试、前端构建、`go test ./...` 和 `go vet ./...` 全部通过。
- 手动 OIDC 登录及深链接导航验证通过。
- `doc/ROADMAP.md` 中对应任务状态已按实际结果更新。
